模板层次速查表 ​

前端请求类型 → 模板文件优先级（从上到下，第一个命中即停） ​

请求场景命中顺序（最具体 → 最通用）
单篇文章（Single Post）single-{post_type}.php → single.php → singular.php → index.php
单条 CPTsingle-{post_type}.php → single.php → singular.php → index.php
页面（Page）{custom-template}.php（页面属性中指定的模板） → page-{slug}.php → page-{id}.php → page.php → singular.php → index.php
文章归档（Post Archive）home.php（首页文章列表） → index.php
分类归档（Category）category-{slug}.php → category-{id}.php → category.php → archive.php → index.php
标签归档（Tag）tag-{slug}.php → tag-{id}.php → tag.php → archive.php → index.php
作者归档（Author）author-{nicename}.php → author-{id}.php → author.php → archive.php → index.php
日期归档（Date）date.php → archive.php → index.php
自定义分类法归档taxonomy-{taxonomy}.php → taxonomy-{taxonomy}-{term}.php → taxonomy.php → archive.php → index.php
自定义 CPT 归档archive-{post_type}.php → archive.php → index.php
搜索结果（Search）search.php → index.php
404 页面404.php → index.php
首页 / Front Pagefront-page.php（无论设为最新文章还是静态首页） → home.php（博客列表页） → page.php → index.php

命名规则：{post_type} 与 {taxonomy} 使用 register_post_type() / register_taxonomy() 时的注册名原样，区分大小写（推荐全小写 + 连字符）。例如注册名 product_cat 则模板文件为 taxonomy-product_cat.php。

高频钩子表 ​

钩子类型触发时机常见用途
initAction核心初始化完成、用户已识别、但头未发注册 CPT/分类法、初始化会话
plugins_loadedAction所有插件已加载完毕，主题尚未加载插件间互调依赖、加载多语言
after_setup_themeAction当前主题已激活，functions.php 已加载注册菜单、侧栏、主题特性、图像尺寸
wp_enqueue_scriptsAction前台样式/脚本队列即将输出wp_enqueue_style() / wp_enqueue_script()
admin_menuAction后台侧边栏菜单已构建但尚未输出注册自定义顶级菜单或子菜单页
save_postAction文章（含自动保存）被保存后触发同步自定义字段、发布后钩子
widgets_initAction小工具系统初始化register_sidebar() 注册侧栏容器
rest_api_initActionREST API 已初始化（用于注册自定义路由）register_rest_route() 注册端点
the_contentFilter文章内容即将输出到浏览器追加版权信息、自动替换短代码
wp_title / document_title_partsFilter页面 <title> 即将组装自定义 SEO 标题结构

陷阱：save_post 会触发自动保存；内部先判断 defined('DOING_AUTOSAVE') 再执行自定义逻辑。

条件标签表 ​

标签返回含义常见陷阱
is_single()bool单篇文章（任意 post_type）不含页面；is_single('slug') 仅匹配 slug
is_page()bool单个页面is_page('about') 匹配 slug 或 ID
is_home()bool博客文章列表首页（无论是否在根目录）若设静态首页，则 is_home() 为博客文章页
is_front_page()bool站点入口首页（阅读设置里的「首页」）与 is_home() 互斥或重叠，取决于阅读设置
is_archive()bool任意归档页（分类/标签/作者/日期/CPT）不含搜索与 404
is_singular()bool任意单条内容（文章/页面/CPT）即 is_single() || is_page() || is_attachment()
is_category()bool分类归档页is_category('news') 支持 slug/ID/名称
is_tag()bool标签归档页同 category
is_tax()bool自定义分类法归档页is_tax('genre', 'sci-fi')
is_post_type_archive()bool自定义 CPT 归档页仅对 has_archive => true 的 CPT
has_post_thumbnail()bool当前文章设置了特色图像必须在 Loop 内或传入 $post->ID
is_search()bool搜索结果页空搜索也会命中
is_404()bool404 未找到页应在查询完成后使用
current_user_can('manage_options')bool当前用户拥有指定能力权限检查不要只按 role，要按 capability

组合陷阱：判断「博客首页且非静态首页」应写 is_home() && ! is_front_page()；判断「文章详情页且不是附件」应写 is_single() && ! is_attachment()。

转义与清洗对照表 ​

输出转义（Escaping — 显示前最后一步） ​

函数适用场景一句话说明
esc_html( $text )任意纯文本输出到 HTML把 < > & " 转成实体，防止 XSS
esc_attr( $text )属性值（value=""、alt=""）额外转义引号与换行，适合 HTML 属性语境
esc_url( $url )链接地址（href、src）拒绝非法协议，保留 http/https/mailto 等白名单
esc_url_raw( $url )写数据库或重定向前同 esc_url 但不转义 &，用于 PHP 跳转
esc_textarea( $text )<textarea> 内文本把 \n 保留，转义标签与引号
esc_sql( $data )手写 SQL 时（优先用 $wpdb->prepare）仅做简单的 addslashes 转义，不足以防御注入
wp_kses_post( $content )允许富文本（如评论、用户 HTML）按「文章」白名单保留标签，其余剥离
wp_kses( $content, $allowed_html )需要自定义标签白名单时显式传入允许的标签与属性数组

输入清洗（Sanitization — 保存到数据库前） ​

函数适用场景一句话说明
sanitize_text_field( $str )单行文本、标题、用户名剥离标签、去除多余空白与非法字符
sanitize_textarea_field( $str )多行文本同 sanitize_text_field 但保留换行
sanitize_email( $email )邮箱地址去除非法字符，不验证域名是否存在
sanitize_url( $url )URL 字段只允许合法协议，自动加 http:// 若缺失
absint( $number )必须为正整数（如 ID、分页）abs( intval( $number ) )，负值归零
wp_kses_post( $content )用户提交的富文本保存前输入清洗与输出转义可用同一函数
rest_sanitize_boolean( $val )REST API 布尔参数兼容 true/1/'1'/false/0/'' 等输入

铁律：保存前 sanitize，显示前 escape；永远不要信任用户输入，也永远不要信任数据库里的值。

WP-CLI 高频命令 ​

core ​

bash
wp core download --locale=zh_CN          # 下载中文版核心
wp core install --url=... --title=... --admin_user=... --admin_password=... --admin_email=...
wp core update                           # 升级核心
wp core verify-checksums                 # 校验核心文件完整性

plugin ​

bash
wp plugin list                           # 列出所有插件
wp plugin install wordfence --activate   # 安装并激活
wp plugin update --all                   # 批量更新插件
wp plugin deactivate hello               # 停用（排障第一步）

theme ​

bash
wp theme list
wp theme install twentytwentyfive --activate
wp theme delete old-theme

db ​

bash
wp db export backup.sql                  # 导出数据库
wp db import backup.sql
wp db size --tables                      # 查看各表体积
wp db query "SHOW TABLES;"

search-replace ​

bash
wp search-replace 'http://old.com' 'https://new.com' --dry-run
wp search-replace 'http://old.com' 'https://new.com' --skip-columns=guid

user ​

bash
wp user list --role=administrator
wp user create editor1 editor@example.com --role=editor --user_pass=TempPass123!
wp user update 1 --user_pass=NewPass!    # 重置管理员密码

cache / rewrite / cron ​

bash
wp cache flush                           # 清空对象缓存
wp rewrite flush --hard                  # 刷新重写规则（若 .htaccess 可写）
wp cron event list                       # 查看定时任务
wp cron event run --due-now              # 立即执行到期任务

export / import ​

bash
wp export --dir=./exports/ --post_type=post
wp import ./exports/site.wordpress.2026-10-04.000.xml --authors=create

wp-config.php 常量速查 ​

常量说明推荐值 / 用法
WP_DEBUG开启调试模式，显示 PHP 报错与通知define( 'WP_DEBUG', true ); 仅限开发/排障
WP_DEBUG_LOG把报错写入 wp-content/debug.logdefine( 'WP_DEBUG_LOG', true ); 线上排障用
WP_DEBUG_DISPLAY是否把报错直接打印到页面线上设为 false，配合 WP_DEBUG_LOG
DISALLOW_FILE_EDIT禁用后台「主题/插件编辑器」define( 'DISALLOW_FILE_EDIT', true ); 生产环境必开
WP_POST_REVISIONS文章修订版本最大保留数define( 'WP_POST_REVISIONS', 10 ); 设为 false 则禁用
WP_MEMORY_LIMITPHP 内存上限（前端）define( 'WP_MEMORY_LIMIT', '256M' );
WP_MAX_MEMORY_LIMIT后台内存上限define( 'WP_MAX_MEMORY_LIMIT', '512M' );
FORCE_SSL_ADMIN强制后台走 HTTPSdefine( 'FORCE_SSL_ADMIN', true );
AUTOSAVE_INTERVAL自动保存间隔（秒）define( 'AUTOSAVE_INTERVAL', 120 ); 减少数据库写入
EMPTY_TRASH_DAYS回收站保留天数define( 'EMPTY_TRASH_DAYS', 7 ); 设为 0 则直接删除
FS_METHOD文件系统写入方式define( 'FS_METHOD', 'direct' ); 仅当自动更新报权限错时使用

位置：所有 define() 必须写在 /* That's all, stop editing! Happy publishing. */ 之前。

WP_Query 三条件查询骨架 ​

php
/**
 * 按分类 + 标签 + 作者三条件筛选文章
 *
 * @return WP_Query 查询实例
 */
function yourprefix_get_filtered_posts() {
	$args = array(
		'post_type'      => 'post',
		'posts_per_page' => 12,
		'paged'          => get_query_var( 'paged' ) ? get_query_var( 'paged' ) : 1,
		'tax_query'      => array(                         # 分类与标签组合
			'relation' => 'AND',
			array(
				'taxonomy' => 'category',
				'field'    => 'slug',
				'terms'    => 'news',
			),
			array(
				'taxonomy' => 'post_tag',
				'field'    => 'slug',
				'terms'    => 'featured',
			),
		),
		'author_name'    => 'editor-li',                   # 作者筛选
		'orderby'        => 'date',
		'order'          => 'DESC',
		'no_found_rows'  => false,                         # 需要分页则保留
	);

	return new WP_Query( $args );
}

enqueue 标准骨架（前台） ​

php
/**
 * 加载主题样式与脚本
 */
function yourprefix_enqueue_assets() {
	$theme_version = wp_get_theme()->get( 'Version' );
	$asset_url     = get_template_directory_uri() . '/assets/';

	wp_enqueue_style(
		'yourprefix-main',
		$asset_url . 'css/main.css',
		array(),
		$theme_version
	);

	wp_enqueue_script(
		'yourprefix-app',
		$asset_url . 'js/app.js',
		array( 'jquery' ),        # 依赖 jQuery（核心自带）
		$theme_version,
		true                      # 放 </body> 前
	);

	# 本地化传参（PHP → JS）
	wp_localize_script(
		'yourprefix-app',
		'yourprefixData',
		array(
			'ajaxUrl' => admin_url( 'admin-ajax.php' ),
			'nonce'   => wp_create_nonce( 'yourprefix_nonce' ),
		)
	);
}
add_action( 'wp_enqueue_scripts', 'yourprefix_enqueue_assets' );

短代码骨架 ​

php
/**
 * 注册一个带参数的短代码 [cta_box title="..." link="..."]
 *
 * @param array  $atts    用户传入的属性。
 * @param string $content 闭合短代码的包裹内容。
 * @return string 渲染后的 HTML。
 */
function yourprefix_cta_box_shortcode( $atts, $content = '' ) {
	$atts = shortcode_atts(
		array(
			'title' => __( '立即行动', 'yourprefix' ),
			'link'  => '#',
		),
		$atts,
		'cta_box'
	);

	$title = esc_html( $atts['title'] );
	$link  = esc_url( $atts['link'] );

	ob_start();
	?>
	<div class="cta-box">
		<h3><?php echo esc_html( $title ); ?></h3>
		<div class="cta-content">
			<?php echo wp_kses_post( $content ); ?>
		</div>
		<a href="<?php echo esc_url( $link ); ?>" class="cta-button">
			<?php esc_html_e( '了解更多', 'yourprefix' ); ?>
		</a>
	</div>
	<?php
	return ob_get_clean();
}
add_shortcode( 'cta_box', 'yourprefix_cta_box_shortcode' );

故障速查表 ​

症状第一反应详见章节
前台/后台全白，无报错开启 WP_DEBUG_LOG，看 wp-content/debug.log；若无法改文件，先改 wp-config.php第 38 章 38.2 节

数据库连接错误四步走：1) 确认 wp-config.php 四项信息正确；2) 用 mysql 客户端直连测试；3) 检查 MySQL 进程；4) 检查磁盘是否满第 38 章 38.4 节

页面出现横向滚动条用浏览器 DevTools 检查 overflow 与固定宽度元素；常见 culprit 是未做响应式的表格或图片第 14 章
搜索/归档页无结果检查是否误用 query_posts()；确认 pre_get_posts 没有过度过滤；刷新重写规则第 24 章
邮件发送失败确认 SMTP 插件配置正确；检查服务器 25/465/587 端口是否被防火墙拦截；看服务商退信日志第 21 章

文件权限速查 ​

对象推荐权限说明
目录（wp-content/ 等）755属主可读写执行，组与其他用户只读+执行
文件（.php、.css、.js）644属主可读写，其他只读
wp-config.php640 或 600绝不可全局可读，生产环境建议 600
.htaccess644若由 WordPress 自动更新则保持可写；加固后可为 644
wp-content/uploads/755（或 775 若多用户上传）必须让 PHP 进程有写入权
备份文件 / SQL 导出600含敏感信息，严格限制读取

属主原则：网站目录的属主应与 PHP-FPM 运行用户一致（常见为 www-data / nginx / apache），避免 777。
