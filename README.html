WordPress 从入门到精通系统教程 ​

线上文档站：https://yzhijie.github.io/wordpress-tutorial-site/（push 到 main 后由 GitHub Actions 自动构建并发布到公开部署仓）

一套面向零基础读者、由浅入深的 WordPress 系统教程：从本地环境搭建、内容管理、主题与插件使用，到主题/插件开发、性能与安全优化、迁移与运维，覆盖 使用者 → 建站者 → 开发者 的完整成长路径。每章包含「学习目标 → 原理说明 → 点击级操作 → 常见问题 → 总结 → 动手练习」，并配套可直接运行的示例主题、插件与环境配置。

版本基线（2026 年 10 月校对） ​

组件推荐版本最低可运行说明
WordPress7.1.x（2026-08 发布）6.x本教程界面以 7.x 默认后台为准，差异处会标注 6.x
PHP8.3 / 8.47.4（已 EOL，不推荐）兼容范围 8.2–8.5；生产环境禁用 8.1 及以下
MySQL8.0+（8.4 推荐）5.5.5支持 8.0 / 8.4 / 9.x
MariaDB10.11+（LTS）5.5.5兼容 10.11 / 11.4 / 11.8 / 12.x
Web 服务器Apache 2.4 / Nginx 1.24+任意支持 PHP 的服务器Apache 需启用 mod_rewrite
HTTPS强制—2026 年所有安装均要求 HTTPS
编辑器区块编辑器（Gutenberg）—经典编辑器以官方插件形式可选安装

数据来源：wordpress.org/about/requirements 与 Hosting Handbook 兼容矩阵。

在线版 / PDF / 视频交付说明 ​

  • 在线版本：本教程基于 VitePress 构建。在本目录执行：

    bash
    pnpm install        # 或 npm install
pnpm docs:dev       # 本地预览 http://localhost:5173
pnpm docs:build     # 产物输出到 .vitepress/dist，可部署到 GitHub Pages / Netlify / Vercel

  • PDF 版本：pnpm docs:build 后用浏览器打开生成的静态站点，通过「打印 → 另存为 PDF」逐模块导出；或使用社区方案 vitepress-export-pdf。详见 videos/storyboards.md 末尾的导出指引。

  • 教学视频：本仓库提供关键操作的分镜脚本与旁白文案（videos/storyboards.md），使用 OBS / QuickTime / WPS 录屏按脚本录制即可，建议分辨率 1920×1080、30fps。

  • 截图：教程中以 screenshots/ 下的规范文件名预留了截图位，按 screenshots/README.md 的拍摄清单补图即可，图片放入对应路径后在线版自动显示。

如何使用本教程 ​

  1. 第一遍按顺序学：每章开头有明确学习目标，结尾有 3–5 道动手练习，练习编号格式为 练-CC-NN（CC=章节号）。
  2. 边学边练：配合 examples/ 的 Docker 环境，所有代码均可直接复制到本地运行。
  3. 先跑通再优化：每遇到一个技术点，先按「操作方法」复现，再回头读「原理说明」，最后看「常见问题」避坑。
  4. 卡住时查附录：术语表查概念、速查卡查函数、第 38 章查报错。
