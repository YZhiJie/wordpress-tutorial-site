第 7 章 区块编辑器全解析 🟢 ​

一句话导览：区块编辑器（Gutenberg）是 WordPress 7.1 的默认编辑器，本章从「区块是什么」讲起，带你吃透界面、核心区块、模式、可复用部件与排障方法，彻底告别复制粘贴式排版。

上一章我们在文章编辑器里完成了发布全流程，本章回到「写作与排版」本身。区块编辑器自 WordPress 5.0 起成为默认编辑器，它不只是一个新的输入框，而是一套结构化的内容组织方式。学会用「区块」思考，你会发现复杂版面不再需要手写表格和 <div>。

学习目标 ​

  • 理解 Gutenberg 的由来与「区块即结构化内容」的思想，看懂文章保存后的 wp: 标记。
  • 熟悉编辑器界面的每个区域：顶栏、插入器、画布、区块工具栏、设置面板、列表视图。
  • 掌握五类核心区块的用途与区块的通用操作（移动、变换、分组、复制、锁定、复用）。
  • 理解模式（Pattern）与可复用部件（同步模式）的区别，能独立完成两栏图文加 CTA 卡片布局。
  • 记住常用键盘快捷键，知道何时需要经典编辑器插件，并能处理「无效区块」这类常见故障。

7.1 Gutenberg 的由来 ​

原理说明 ​

在 WordPress 5.0（2018 年底发布）之前，WordPress 使用的是 TinyMCE 经典编辑器——一个类似简化版 Word 的单一文本框，工具栏提供加粗、对齐、插入图片等按钮。它的问题很明显：

  • 内容是一整坨混合 HTML，复杂版面靠嵌套表格和内联样式拼凑。
  • 想做一个「左图右文 + 按钮」的卡片，要么手写 HTML，要么依赖页面构建器插件。
  • 内容样式与主题强耦合，换主题后排版经常散架。

Gutenberg（古腾堡） 项目以印刷术发明者命名，目标是把页面拆成一个个独立的「区块（Block）」：一段文字是段落区块，一张图片是图片区块，一列按钮是按钮区块。每个区块负责自己的结构、样式与设置，编辑器把它们组合成完整页面。

经过多个大版本的演进，7.1 时代的 Gutenberg 已经从「文章编辑器」扩展为**全站编辑（Full Site Editing）**的基础：小工具、导航菜单、页眉页脚、模板都由区块构成（主题侧的全站编辑在第 13 章与第 23 章展开）。

常见问题 ​

  • 问：Gutenberg 是插件吗？ 答：它有两种形态：核心代码已随 WordPress 自带；同时官方还在插件目录发布「Gutenberg」插件，那是抢先体验最新开发功能的测试通道，普通站点不需要安装。

7.2 区块底层原理：内容是怎么保存的 ​

原理说明 ​

在经典编辑器里，文章正文就是普通 HTML。而在区块编辑器里，正文是带 HTML 注释标记的 HTML。点击任意区块工具栏的「选项（三点）→ 编辑为 HTML」（Edit as HTML），或按 Ctrl/Cmd + Shift + Alt + M 切换到代码编辑器，你会看到类似内容：

html
<!-- wp:heading {"level":2} -->
<h2>为什么选择区块</h2>
<!-- /wp:heading -->

<!-- wp:paragraph {"align":"center"} -->
<p class="has-text-align-center">这是一段居中的文字，包含一个<strong>加粗</strong>词汇。</p>
<!-- /wp:paragraph -->

<!-- wp:image {"id":128,"sizeSlug":"large","linkDestination":"none"} -->
<figure class="wp-block-image size-large"><img src="https://example.com/wp-content/uploads/2026/10/team.jpg" alt="团队合影" class="wp-image-128"/></figure>
<!-- /wp:image -->

规律非常清晰：

  • <!-- wp:区块名 --> 与 <!-- /wp:区块名 --> 是一对分隔注释，包裹该区块输出的 HTML。
  • 注释中可以携带 JSON 配置（如 {"align":"center"}），区块设置面板里的选项就保存在这里。
  • 没有任何配置的简单区块就是 <!-- wp:paragraph -->。
  • 还有一类自闭合的动态区块，如 <!-- wp:latest-posts {"postsToShow":3} / -->，正文里不存渲染结果，而是在前台访问时由 PHP 实时查询输出——所以「最新文章」区块永远显示最新数据。

为什么这比短代码（Shortcode）时代更可移植 ​

经典时代插件常让用户在正文里写短代码：[gallery id="5" columns="3"]、[contact-form id="7"]。对比一下：

对比维度经典编辑器 + 短代码区块编辑器 + 区块标记
编辑体验一行看不懂的方括号文本，靠弹窗填参数可视化，所见即所得
内容结构编辑器不知道 [gallery] 占多大、是什么每个区块在画布中有真实结构
卸载插件后正文中残留 [xxx] 纯文本区块标记不匹配时提示「无效区块」，可保留内容或转 HTML
数据格式插件私有语法，无法被其他工具解析标准 HTML 注释 + JSON，任何工具都能识别处理
响应式与样式依赖插件/主题输出，难以统一区块自带结构化 class，主题可统一设计

一句话：短代码是「给程序看的暗号」，区块标记是「人和程序都能读懂的结构化文档」。

常见问题 ​

  • 问：我可以直接改这些 wp: 注释吗？ 答：学习时可以观察，日常排版不要手改。一旦注释与内部 HTML 不匹配，区块会报「无效」。改完想验证，可切回可视化编辑器。
  • 问：换主题后区块会丢吗？ 答：区块标记随文章保存在数据库中，与主题无关，内容不会丢；但区块的某些样式（字体、配色）会随主题变化呈现不同外观，这是设计使然。

7.3 认识编辑器界面 ​

我们先从添加内容的入口——插入器看起，再总览全局。

7.3.1 插入器（Inserter） ​

点击编辑器顶部的「+」按钮（或区块工具栏上的「+」），打开的面板就是插入器。它分为「区块」「模式」「媒体」等标签页：

  • 区块：按文本、媒体、设计、小工具、主题等分类列出所有可用区块，顶部搜索框支持拼音/英文/功能模糊搜索（搜「图」能找到图片、图库、封面）。
  • 模式：一组预设好的区块组合（整套 CTA、价格表、联系区），一键插入再改文字（详见 7.8 节）。
  • 媒体：直接浏览媒体库并插入图片、音频、视频。

图 07-1：区块插入器面板，左侧为分类标签与搜索框，右侧显示区块/模式预览网格

更快的插入方式是斜杠命令：在一个空段落里直接输入 /，立刻弹出可插入区块列表，继续输入 图片、标题、表格 等关键词，按回车即插入。熟练后 90% 的插入操作都不需要移动鼠标。

7.3.2 界面全景 ​

图 07-2：区块编辑器全景，依次标注顶栏、列表视图、插入器、画布、区块工具栏、文档/区块设置面板

区域位置作用
顶部栏窗口最上方返回、列表视图、插入器、文档/区块设置切换齿轮、预览、发布/更新、选项（三点）
左侧面板点「+」展开插入器（区块/模式/媒体）
列表视图顶栏按钮或 Shift+Alt+O以树形大纲显示全部区块，用于定位、拖拽、批量选择、锁定
画布中央写作与排版的主区域
区块工具栏选中区块时浮现变换、移动、对齐、加粗/斜体、链接、本区块的专属操作与选项菜单
设置面板右侧（齿轮开关）上半部分「文档」管整篇文章（状态、分类、特色图）；选中区块后切换为「区块」设置，管当前区块的所有参数

右侧面板顶部有两个标签（面包屑式切换）：文章/页面设置与区块设置。很多新手找不到「图片怎么设链接」「按钮怎么改颜色」，都是因为停留在文档设置标签，选中区块后点击齿轮旁的「区块」标签即可。

图 07-3：选中图片区块后的右侧设置面板，包含替代文本、尺寸、链接目标等区块专属选项

操作方法：你的第一个区块操作 ​

  1. 新建文章，在空段落输入 /标题，回车插入「标题」区块，输入文字。
  2. 按回车自动新建段落，输入 /图，选择「图片」区块。
  3. 点击「上传」选择本地图片，上传后图片直接出现在画布中。
  4. 保持图片选中，在右侧区块设置的「替代文本」框填写无障碍描述。
  5. 点击右上角「预览」，在新标签查看前台效果。

常见问题 ​

  • 问：右侧设置面板不见了？ 答：点击顶部右上角的齿轮图标切换显示；再确认选中了具体区块，否则显示的是文档设置。
  • 问：搜索不到某个区块？ 答：该区块可能由插件提供而插件未启用，或被当前主题/管理员代码禁用；内置区块缺失时切换默认主题并停用插件排查。

7.4 核心区块分组讲解 ​

内置区块按功能分为五大类，下面列出最常用的区块与典型用途。

文本类 ​

区块中文名称用途与要点
core/paragraph段落最基础的正文单元；回车即新建段落
core/heading标题H1-H6；文章主标题由模板提供，正文从 H2 开始用，勿跳级
core/list列表有序/无序，支持缩进多级；不要再用空格手动作列表
core/quote引用引文样式，含引用文字与署名
core/code代码行内代码片段样式，等宽字体显示，HTML 会被转义显示
core/preformatted前置格式化保留空格与换行的纯文本，适合 ASCII 示意
core/table表格简单表格，可设置表头、分段样式；复杂数据表仍建议电子表格截图或专业插件
core/verse诗歌保留换行排版的诗文
core/pullquote拉引版面中的大字强调引语

媒体类 ​

区块中文名称用途与要点
core/image图片单图，支持替代文本、尺寸、链接目标、圆角样式（媒体管理见第 8 章）

core/cover封面大图/视频背景上叠加文字，适合页头横幅

core/file文件PDF/压缩包下载链接，带下载按钮
core/embed嵌入粘贴 URL 自动转换为 YouTube、Twitter 等嵌入内容

设计类 ​

区块中文名称用途与要点

core/spacer间隔纯留白高度，可拖高度，用于调节版面呼吸感

主题类 ​

这类区块从网站本身读取动态数据，常用于文章正文、小工具区和模板：

区块中文名称用途
core/latest-posts最新文章自动列出最新文章，可按分类过滤、显示日期/特色图
core/archives归档按月列出文章归档链接
core/latest-comments最新评论展示最新评论片段
core/tag-cloud分类云标签/分类字号云
core/shortcode短代码在区块世界里承载旧插件短代码的桥
core/html自定义 HTML直接写原生 HTML（统计代码、第三方嵌入脚本）

小工具类 ​

区块中文名称用途
core/search搜索站内搜索框
core/social-links社交链接微博、微信、GitHub 等社交图标链接组

7.5 区块通用操作 ​

所有区块共享一套相同的操作语言，学会一个就会用全部。

操作怎么做说明
选中单击区块出现区块边框与工具栏
选中外层容器按 Esc 或点击底部面包屑的父级名在组/栏目中尤其常用
上移/下移工具栏的 ↑/↓ 箭头逐格移动
拖拽按住区块左侧的拖柄（六点图标）拖动出现蓝色指示线表示落点
变换（Transform）工具栏左侧的区块图标段落 ↔ 标题、列表 ↔ 引用、组 ↔ 行列等，保留文字
对齐工具栏对齐按钮左/中/右/宽幅/全宽（后两者需主题支持，见 FAQ）
复制选项（三点）→ 复制，或 Ctrl/Cmd + Shift + D 复制出一个相同区块「复制」是到剪贴板，可跨文章粘贴
重复选项 → 重复原地生成副本
在前方/后方插入选项 → 插入前/插入后精确控制插入位置
分组选项 → 用组包裹（Group）把当前区块包进组容器，便于加背景
移除选项 → 移除，或选中后按删除键内容随之删除，可 Ctrl/Cmd+Z 撤销
锁定选项 → 锁定（Lock）禁止移动/删除，模板中防止客户误改
复用选项 → 创建可复用部件/模式见 7.8 节

操作方法：用拖柄与面包屑操作嵌套区块 ​

  1. 插入一个「组」，组内放三个段落。
  2. 选中第二个段落，按 Esc，选中焦点上移到「组」——观察底部面包屑显示「文章 › 组 › 段落」。
  3. 抓住段落工具栏左侧的拖柄上下拖动，组内出现蓝色横线指示落点。
  4. 选中组，在区块设置中为整个组设置背景色，三个段落一起变色。

常见问题 ​

  • 问：拖拽时总是掉错位置？ 答：嵌套布局中直接拖容易误判层级。复杂移动改用 7.7 节的列表视图，拖放位置更精确。
  • 问：「用组包裹」后后悔了？ 答：选中组 → 工具栏选项 →「解组」（Ungroup），容器消失，内部区块保留。

7.6 区块样式 ​

原理说明 ​

同一个区块可以有多种预设外观，称为区块样式（Block Styles）。例如图片区块有「默认」「圆形」（圆角裁切成圆）；按钮有「填充」「轮廓」；表格有「默认」「条纹」。它在区块工具栏或右侧设置面板的「样式」区域以缩略图/按钮形式出现。

区块样式由核心、主题或插件注册，本质是给区块 HTML 追加一个修饰 class（如 is-style-rounded），切换样式不改变内容，只换外观。

操作方法 ​

  1. 插入一个按钮区块并输入文字。
  2. 在右侧区块设置的「样式」中，在「填充」与「轮廓」之间切换，观察画布。
  3. 插入图片区块，在「样式」中选「圆形」，图片立即变为圆形裁切。
  4. 在「颜色」「排版」「尺寸」等折叠面板中还可以做更细的局部覆盖。

常见问题 ​

  • 问：别人截图里的样式我这里没有？ 答：部分样式由主题注册（如特定按钮形状）。换用支持该样式的主题，或由开发者通过代码注册默认样式（第 22 章后的主题开发内容）。

7.7 列表视图：复杂版面的导航仪 ​

原理说明 ​

当文章有几十个区块、出现三四层嵌套时，在画布中精准选中某个区块会变得困难。列表视图（List View） 把整篇文章展开成一棵可折叠的树：

text
文章
├─ 封面
├─ 组（特性区）
│  ├─ 标题（H2）
│  ├─ 栏目
│  │  ├─ 列
│  │  │  └─ 段落 ×3
│  │  └─ 列
│  └─ 按钮
└─ 分隔符

在列表视图中可以：单击直接定位并选中深层区块；按住拖柄上下拖动调整顺序与层级；按住 Shift 多选后整体移动；已锁定区块显示锁形图标。

图 07-4：列表视图中的嵌套区块树，拖柄、锁形标记与选中高亮清晰可见

操作方法 ​

  1. 按 Shift+Alt+O（macOS 为 Shift+Option+O）打开列表视图。
  2. 点击树中某个区块，画布自动滚动并选中它。
  3. 按住 Shift 连选两个区块，拖动整组到封面之前。
  4. 右键区块名 →「锁定」，在弹窗中勾选「禁止移动」「禁止删除」，回画布验证工具栏变灰。

7.8 模式与可复用部件 ​

原理说明 ​

模式（Pattern） 是官方设计好的区块组合模板：一整套「关于我」简介卡、三栏价格表、FAQ 折叠区、带背景图的行动号召区。插入后内容完全属于你，随意修改，互不影响——这叫非同步模式（Non-synced Pattern）。

可复用部件（旧称「可复用区块」，WordPress 6.3 后归入同步模式 Synced Pattern）是另一种用法：把一个区块（或一组区块）保存为命名部件，之后可以插入到任意文章/页面。它的关键特性是：所有插入位置共享同一个数据源，改一处，全站所有位置同步更新。

对比模式（普通 Pattern）可复用部件（同步模式）
插入后修改只影响本篇这一处默认进入「部件编辑」，改动全站同步
典型用途快速搭一个价格表骨架全站统一的 CTA 卡片、订阅提示、联系方式块
能否解耦本来就独立可在某一处「脱离/转为普通区块」成为独立副本
管理位置插入器「模式」标签 / 主题目录站点编辑器 → 模式 → 我的模式（同步模式管理库）

图 07-5：站点编辑器中的模式管理界面，「我的模式」下列出全部可复用部件，可重命名、编辑与导出

操作方法：创建并使用一个可复用 CTA 部件 ​

  1. 在文章中插入一个「组」：内部放一个标题（「还没决定？先免费试用 14 天」）、一个段落、一个按钮（文字「立即开始」）。
  2. 为组设置背景色与内边距，排版满意后选中整个组。
  3. 点击组工具栏「选项（三点）→ 创建可复用部件/模式」，命名为「全站 CTA-免费试用」，确认保存。
  4. 新开一篇文章，用插入器的「模式 → 我的模式」或搜索部件名，把它插入正文。
  5. 回到第一篇文章，点击该部件上的「编辑部件/模式」，把按钮文案改为「免费注册」，更新。
  6. 刷新第二篇文章查看——按钮文案已同步改变，这就是「改一处、全站变」。

模式还可以从官方模式目录浏览导入；区块主题会自带大量主题级模式。主题侧的模式注册将在第 23 章学习。

常见问题 ​

  • 问：只想在这篇文章里改这个部件，怎么办？ 答：在该实例工具栏选项中选择「脱离/分离为常规区块」（Detach），它就变成普通区块副本，与同步部件再无关联。
  • 问：删除可复用部件会影响已插入的文章吗？ 答：删除部件后，已有实例会提示失效，可按提示转为普通区块保留内容；删除前建议先检查引用位置。

7.9 实操：两栏图文 + CTA 卡片 ​

下面用点击级步骤做一个完整版面：上方两栏图文，下方一个整宽 CTA 卡片。

  1. 新建空白文章，先输入 /行列，插入「栏目/行列」（Columns）区块，在弹出的预设中选择两个等宽列。
  2. 点击左列中的「+」，插入「标题」（H3）输入「自动备份，安心睡觉」，再插一个段落写两三句介绍。
  3. 点击右列中的「+」，插入「图片」区块，从媒体库选图（无图时先上传，方法见第 8 章）。
  4. 选中最外层「栏目」区块，在右侧设置中把「垂直对齐」设为「居中」；在「列间距」中调宽两列间距。
  5. 在栏目区块下方新建区块：输入 /组 插入「组」，在组内依次放一个 H2 标题、一个段落、一个「按钮」区块。
  6. 选中「组」，在区块设置中设置背景色、文字颜色、内边距；选中「按钮」，设置链接与轮廓样式。
  7. 如果想让 CTA 在窄屏上更舒展，可把组的对齐设为「宽幅」（需主题支持 align-wide，见 FAQ）。
  8. 点击「预览」检查移动端：浏览器开发者工具切到手机视图，确认两栏自动堆叠、按钮可点。
  9. 满意后按 7.8 节把组保存为可复用部件，供其他文章复用。

7.12 与经典编辑器共存 ​

原理说明 ​

官方插件目录提供 Classic Editor（经典编辑器） 插件，启用后可恢复 TinyMCE 界面，并且与区块编辑器共存：

  • 全站默认编辑器可在「设置 → 撰写」中选择经典或区块。
  • 文章列表会出现「使用经典编辑器编辑」「使用区块编辑器编辑」两种入口。
  • 区块编辑器中保留了一个 「经典」区块（Classic Block）：它在画布中嵌入一个 TinyMCE 小编辑器，适合维护那些大量依赖旧编辑器按钮/短代码的老文章。

图 07-6：左侧为经典编辑器单一文本框，右侧为区块编辑器的结构化画布与区块工具栏

什么时候该装经典编辑器？

场景建议
新站、新内容不装，直接学区块编辑器
老站几百篇旧文、作者群体拒绝改变可装，逐步过渡，作者可逐篇尝试
某些老旧插件只能在经典编辑器里通过按钮插短代码可装，或用「经典」区块/短代码区块局部兼容
页面构建器（Elementor 等）重度站点与构建器插件并行使用，文章仍建议用区块

经典编辑器是官方维护的兼容工具，不是「更专业」的选择。新内容坚持用区块，长期可移植性最好。

常见问题 ​

  • 问：装了经典编辑器后还能用区块吗？ 答：可以。两种编辑器并行，旧文用经典打开、新文用区块写；同篇文章也可以反复切换（区块内容在经典编辑器中会显示为区块标记/区块占位，尽量固定一种编辑器维护同一篇文章）。

7.13 无效区块与恢复失败 ​

原理说明 ​

打开旧文章时偶尔会看到红色提示：「此区块已损坏或无效」「此区块已被删除或停用」。常见原因：

  1. 提供该区块的插件被停用或卸载，编辑器不认识标记了。
  2. 插件/主题升级后区块输出结构发生变化，与已保存的 HTML 对不上。
  3. 手动粘贴/代码编辑改坏了 wp: 注释。
  4. 文章是经典编辑器写的、被外部工具修改过 HTML。

处理手段按代价从低到高：

  • 点击「尝试区块恢复」（Attempt Block Recovery），大多数结构轻微不匹配可自动修复。
  • 工具栏选项 →「作为 HTML 编辑」，核对并修正标记后切回可视化。
  • 从修订版本恢复到正常版本（第 6 章 6.3.6）。
  • 若区块来自已卸载插件且确认不再需要：保留内部文字（转成普通区块/自定义 HTML）后删除占位。
  • 若是动态区块（如某插件的轮播），重新启用对应插件即可恢复，正文数据没有丢。

操作方法：故意制造一次失效并修复 ​

  1. 启用一个提供前台区块的插件，插入其区块并更新文章。
  2. 停用该插件，刷新编辑界面，观察「区块无效」提示。
  3. 点击「尝试区块恢复」或先以 HTML 查看残留标记；重新启用插件，区块恢复。
  4. 这就是「插件卸载后内容残留」的真实过程，选型插件时要想到这一步。

7.14 移动端与 WordPress App ​

WordPress 官方 iOS/Android App 内置了移动版区块编辑器，支持段落、标题、图片等常用区块，适合临时发文、改错别字、审核评论；复杂嵌套布局与精细样式仍建议在桌面端完成。App 连接站点走 REST API（Jetpack 或应用密码授权），应用密码在「用户 → 个人资料」底部管理。平板上配合蓝牙键盘，斜杠命令与多数快捷键同样可用。

7.15 常见问题速查 ​

  • 问：从 Word/网页粘贴后变成一堆奇怪区块、格式全乱？ 答：先撤销（Ctrl/Cmd+Z），改用纯文本粘贴：Windows Ctrl + Shift + V、macOS Cmd + Shift + V，再用标题、列表区块重新排版。
  • 问：编辑器白屏或卡在加载动画？ 答：按「禁用插件排查法」处理：停用全部插件后逐个启用，定位冲突插件；同时按 F12 打开浏览器控制台（Console）查看红色报错；管理后台加载的优化类脚本（自定义管理 JS、广告拦截插件）也可能拦截编辑器请求。排查思路同第 38 章。
  • 问：自定义 CSS 类名在哪里填？ 答：选中区块 → 右侧区块设置 → 顶部「高级（Advanced）」折叠区 →「附加 CSS 类」（Additional CSS class(es)）。多个类名用空格分隔。
  • 问：对齐里的「宽幅/全宽」按钮点了没效果？ 答：当前主题没有声明宽幅支持。经典主题需在 functions.php 中加入 add_theme_support( 'align-wide' );，区块主题需在 theme.json 中配置对应布局宽度（第 23 章详解）。
  • 问：为什么改一个可复用部件，全站的都变了？ 答：这正是同步模式的设计：部件只有一份数据源。只改单篇请先「脱离为常规区块」。
  • 问：浏览器意外崩溃，写的内容丢了吗？ 答：大概率没有。自动保存每 60 秒提交一次，本地存储还留有最近输入；重开文章时编辑器会提示恢复本地版本。

本章总结 ​

  1. Gutenberg 自 5.0 取代 TinyMCE，把内容拆成区块；正文以 wp: HTML 注释 + JSON 配置保存，比短代码时代更结构化、更可移植。
  2. 界面五件套：顶栏、插入器（区块/模式/媒体 + 斜杠命令）、画布、区块工具栏、文档/区块双标签设置面板；复杂导航靠列表视图。
  3. 核心区块分文本、媒体、设计、主题、小工具五类；移动、变换、对齐、分组、复制、重复、锁定、复用是所有区块共通的操作语言。
  4. 模式是插入即独立的区块组合；可复用部件（同步模式）是「改一处全站变」的共享部件，可脱离为独立副本；行列 + 组 + 按钮可以搭出主流营销版面。
  5. 经典编辑器插件仅用于老站兼容；遇到无效区块依次尝试自动恢复、HTML 修正、修订恢复、重装插件；白屏与脏格式问题都有标准排查路径。

动手练习 ​

练-07-01：用 8 种区块拼一篇产品介绍长文 新建文章「2026 年 WordPress 新手建站指南」，要求至少使用以下 8 种区块：标题、段落、列表、图片、封面、媒体和文本、行列、按钮（可再加表格/引用）。包含一个两栏布局和一个结尾行动号召区，排版完成后预览移动端堆叠效果，并用列表视图截图记录区块树。

练-07-03：观察插件卸载导致的区块失效 安装任一提供前台区块的官方插件（如某种 CTA/表单区块插件），插入区块并保存文章；停用插件后刷新文章，记录「无效区块」提示与处理选项；尝试「作为 HTML 编辑」找到该插件的 wp: 标记，最后重新启用插件恢复，并在笔记中写下这对内容资产长期维护的启示。

练-07-04：在代码视图中读懂区块标记 打开练-07-01 的文章，切换到代码编辑器（Ctrl/Cmd + Shift + Alt + M），找出至少 5 处 wp: 注释，对照画布中的区块，在笔记中列出「区块名 → JSON 配置 → 实际 HTML」的对应关系；再对任意段落「编辑为 HTML」做一次小改动（如加一个 <strong>），切回可视化确认无误后更新。
