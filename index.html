快速开始配套环境 ​

bash
cd examples
cp .env.example .env     # 修改数据库密码与端口
docker compose up -d     # 启动 WordPress + MySQL + WP-CLI
./bin/setup.sh           # 自动安装站点、激活主题插件、生成演示数据

打开 http://localhost:8080 访问演示站，后台地址 http://localhost:8080/wp-admin 。
